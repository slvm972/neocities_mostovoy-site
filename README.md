# 📁 Структура проекта - Сайт Славы Мостового

## 🗂️ Полная структура файлов

```
project-root/
│
├── index.html                          # Главная страница
├── style.css                           # Стили (без изменений)
├── poetry_complete.json                # Данные поэзии
├── 3.ico                              # Иконка сайта
│
└── js/                                # Папка JavaScript модулей
    │
    ├── config/                        # Конфигурационные файлы
    │   └── translations.js            # Все переводы (150 строк)
    │
    ├── managers/                      # Менеджеры данных
    │   ├── languageManager.js         # Управление языками (50 строк)
    │   ├── mediaManager.js            # Управление медиа (250 строк)
    │   └── adminManager.js            # Админ-функционал (40 строк)
    │
    ├── ui/                            # UI модули
    │   ├── adminUI.js                 # UI админ-панели (200 строк)
    │   ├── modalManager.js            # Модальные окна (100 строк)
    │   └── uiManager.js               # Основной UI (150 строк)
    │
    └── main.js                        # Точка входа (20 строк)
```

## 📋 Описание модулей

### 1. **translations.js** (Конфигурация)
- Содержит все переводы на 4 языка
- Чистый объект данных без логики
- Легко редактировать и добавлять новые языки

### 2. **languageManager.js** (Менеджер языков)
- Определение языка браузера
- Получение переводов по ключам
- Работа с URL параметрами

### 3. **mediaManager.js** (Менеджер медиа)
- Управление новостями, треками, видео
- Работа с localStorage
- Загрузка и рендеринг поэзии
- Нормализация YouTube URL
- Генерация ID для элементов

### 4. **adminManager.js** (Администрирование)
- Секретный вход (3 клика по заголовку)
- Проверка пароля
- Управление сессией админа

### 5. **adminUI.js** (UI админ-панели)
- Формы добавления/редактирования
- Списки медиа-элементов
- Экспорт в JSON
- Сообщения об успехе

### 6. **modalManager.js** (Модальные окна)
- Открытие/закрытие окон
- Просмотр стихов
- Навигация между стихами
- Обработка Escape

### 7. **uiManager.js** (Основной UI)
- Инициализация приложения
- Переключение языков
- Обработчики событий
- Обновление переводов

### 8. **main.js** (Точка входа)
- Запуск приложения
- Инициализация UIManager
- Логирование старта

## 🔄 Порядок загрузки модулей

**ВАЖНО!** Модули должны загружаться в строгом порядке:

```html
<!-- 1. Сначала данные -->
<script src="js/config/translations.js"></script>

<!-- 2. Потом менеджеры данных -->
<script src="js/managers/languageManager.js"></script>
<script src="js/managers/mediaManager.js"></script>
<script src="js/managers/adminManager.js"></script>

<!-- 3. Затем UI -->
<script src="js/ui/adminUI.js"></script>
<script src="js/ui/modalManager.js"></script>
<script src="js/ui/uiManager.js"></script>

<!-- 4. И последней - точка входа -->
<script src="js/main.js"></script>
```

## ✅ Преимущества модульной структуры

### 1. **Читаемость**
- Каждый файл отвечает за одну задачу
- Легко найти нужную функцию
- Понятная иерархия

### 2. **Поддержка**
- Изменения в одном модуле не ломают другие
- Легко добавлять новые функции
- Быстрое исправление багов

### 3. **Совместная работа**
- Разные разработчики могут работать с разными модулями
- Меньше конфликтов при слиянии кода
- Параллельная разработка

### 4. **Тестирование**
- Каждый модуль можно тестировать отдельно
- Проще писать unit-тесты
- Изолированное тестирование функций

### 5. **Производительность**
- Браузер кэширует отдельные файлы
- Можно подгружать модули по требованию
- Лучше для загрузки страницы

## 🛠️ Как работать с модулями

### Добавление нового перевода
Редактируйте только `translations.js`:
```javascript
// js/config/translations.js
const translations = {
  ru: {
    newKey: 'Новый текст'
  },
  // ... остальные языки
}
```

### Добавление новой функции медиа
Редактируйте `mediaManager.js`:
```javascript
// js/managers/mediaManager.js
const MediaManager = {
  // ... существующие методы
  
  newMethod() {
    // Новая функция
  }
}
```

### Добавление нового UI элемента
Редактируйте `uiManager.js`:
```javascript
// js/ui/uiManager.js
const UIManager = {
  // ... существующие методы
  
  renderNewElement() {
    // Новый UI элемент
  }
}
```

## 🚀 Миграция с одного файла

Если у вас старый `script.js`:

1. Создайте папку `js/` с подпапками
2. Скопируйте модули из артефактов
3. Обновите `index.html` на новую версию
4. Удалите старый `script.js`
5. Проверьте работу сайта

## 🔍 Отладка

При возникновении ошибок:

1. **Откройте консоль браузера** (F12)
2. **Проверьте порядок загрузки** - должны быть все 8 файлов
3. **Смотрите на ошибки** - они укажут проблемный модуль
4. **Проверьте пути** - все файлы должны быть в `js/`
